# Class 1: HTML Lists and Tables

## lists.html
Demonstrates different types of HTML lists:
- Ordered lists with starting numbers and different list item types (numeric, uppercase letters)
- Nested ordered lists
- Description lists (`<dl>`, `<dt>`, `<dd>`)

## tables.html
Demonstrates basic HTML table structure with borders, table headers (`<th>`), and table data (`<td>`). Includes styling with inline CSS for border formatting.
