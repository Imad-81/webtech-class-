# Class 1: HTML Lists and Tables

## lists.html

### Overview
Practice exercise covering the three main types of HTML lists.

### Features Demonstrated

- **Ordered lists (`<ol>`)** with:
  - Custom start number (`start="50"`)
  - Different list item markers (`type="A"` for uppercase letters, `type="1"` for numbers)
  - Nested ordered lists (outer list with inner `<ol>`)

- **Description lists (`<dl>`)** with:
  - Terms (`<dt>`) - e.g., "Coffee", "Milk"
  - Descriptions (`<dd>`) - e.g., "Black Hot drink", "White Cold Drink"

### Key Learning Points
- Control list numbering order and starting values
- Nest lists within other list items
- Use description lists for metadata/term-definition pairs

## tables.html

### Overview
Exercise demonstrating basic HTML table structure and styling.

### Features Demonstrated

- Table with borders (1px solid black via inline CSS)
- Table row (`<tr>`) and column structure
- Table headers (`<th>`) vs data cells (`<td>`)
- Full-width table (`style="width: 100%"`)

### Table Data Example

| Company | Contract | Country |
|---------|----------|---------|
| Alfreds Futterkiste | Maria Anders | Germany |
| Centro comercial Mayteza | Francisco Chang | Mexico |

### Key Learning Points
- Semantic use of `<th>` for header cells
- Styling tables with inline CSS
- Table layout and responsiveness basics
