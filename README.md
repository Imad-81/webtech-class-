# webtech-class

Repository for web technology class assignments and examples.

## Course Structure

- `class1/` - HTML Lists and Tables
  - `lists.html` - Ordered lists with start numbers, markers, nesting, and description lists
  - `tables.html` - Basic HTML tables with borders, headers, and data cells

- `class2/` - HTML Forms and Images
  - `forms.html` - Contact form with text inputs and submit button
  - `image.html` - CSS background image properties with text styling

## Technologies

- HTML5 (structural elements, forms, lists, tables)
- CSS3 (inline styling, background images, text formatting)
